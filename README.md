## 🚀 HƯỚNG DẪN 1: LƯU TRỮ VÀ PUBLIC WEB LÊN GITHUB (MIỄN PHÍ)

### Bước 1: Tạo Repository trên GitHub
1. Mở trình duyệt truy cập: **https://github.com/new**
2. Đặt tên repository: `lmt-training`
3. Chọn chế độ: **Public** (Công khai).
4. Nhấn **Create repository**.

### Bước 2: Tải các file lên GitHub bằng trình duyệt Web
1. Tại trang repository mới tạo trên GitHub, nhấn **Upload an existing file** (hoặc nút `Add file` > `Upload files`).
2. Mở thư mục `lmt_website` trên máy tính của bạn và **kéo thả toàn bộ các file** vào khung tải lên của GitHub:
   - `index.html`
   - `database.json`
   - `server.js`
   - `package.json`
   - `railway.json`
   - `Procfile`
   - `README.md`
3. Nhấn nút xanh **Commit changes**. Toàn bộ mã nguồn và cơ sở dữ liệu đã được lưu an toàn trên GitHub!

### Bước 3: Bật đường link Web công khai (GitHub Pages)
1. Trên GitHub repo, bấm tab **Settings** (ở thanh menu phía trên).
2. Chọn mục **Pages** ở cột menu bên trái.
3. Tại phần **Build and deployment**:
   - Source: Chọn `Deploy from a branch`
   - Branch: Chọn `main` (hoặc `master`), thư mục `/ (root)`
   - Nhấn **Save**.
4. Chờ khoảng 1 - 2 phút, trang web sẽ có đường link trực tiếp trên internet dạng:
   `https://<ten-tai-khoan>.github.io/lmt-training/`

## 🚂 HƯỚNG DẪN 2: TRIỂN KHAI DATABASE & BACKEND LÊN RAILWAY (railway.com/new)

Railway là nền tảng điện toán đám mây cho phép chạy ứng dụng fullstack (Node.js + Database) chỉ với 1 cú click từ GitHub:

### Bước 1: Kết nối Railway với GitHub
1. Truy cập: **https://railway.com/new**
2. Đăng nhập bằng tài khoản GitHub của bạn.
3. Chọn **Deploy from GitHub repo**.
4. Chọn repository `lmt-training` mà bạn vừa tạo ở bước trên.

### Bước 2: Khởi chạy và cấp link Web
1. Railway sẽ tự động đọc file `package.json`, `server.js` và `railway.json` để build ứng dụng.
2. Khi build hoàn tất (chấm tròn chuyển màu xanh lá cây):
   - Bấm vào service của bạn trên Railway -> chọn tab **Settings**.
   - Tại mục **Networking**, bấm **Generate Domain** (hoặc Custom Domain).
   - Railway sẽ cấp cho bạn một đường link công khai cực nhanh dạng:
     `https://lmt-training-production.up.railway.app`

### Bước 3: Cơ chế hoạt động của Database
- Mọi khi có khách hàng điền form trên website, hệ thống sẽ tự động gọi REST API `POST /api/leads`.
- Dữ liệu được ghi thẳng vào `database.json` trên máy chủ Railway.
- Bạn có thể vào xem danh sách bất cứ lúc nào qua API `GET /api/leads` hoặc bấm nút **Database Khách Hàng** ngay trên website để tải file Excel hoặc file `database.json` mới nhất về cập nhật lại kho GitHub!
